导出数据和结构

```
docker exec mysql8 mysqldump -uroot -p123456 --routines --triggers --events --default-character-set=utf8mb4 --databases iam > iam_all_full.sql
```

仅导出结构
···
docker exec mysql8 mysqldump -uroot -p123456 --no-data --routines --triggers --events --default-character-set=utf8mb4 --databases iam > iam_ddl_full.sql
···

恢复单库完整文件

```
docker exec -i mysql8 mysql -uroot -p123456 < iam_full.sql
```
