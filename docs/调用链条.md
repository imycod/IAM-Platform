## 序列图

https://www.websequencediagrams.com/app
```
sequenceDiagram
    participant U as 张三浏览器
    participant W as Workflow 前端
    participant IAM as IAM Platform
    participant Id as Identity/Auth
    participant Org as Organization
    participant App as Application
    participant Acc as Access
    participant Sec as Security/OIDC

    U->>W: 访问 workflow.acme.com
    W->>IAM: OIDC 授权跳转
    IAM->>Id: Better Auth 校验身份
    Id-->>IAM: userId = 张三
    IAM->>Org: 加载 employee/department（供数据权限）
    IAM->>App: canUserAccess(workflow, 张三)?
    App-->>IAM: application_user 存在 ✓
    IAM->>Acc: resolveUserPermissionCodes(张三, workflow)
    Acc-->>IAM: [workflow:task:read, workflow:task:create, ...]
    IAM->>Acc: resolveDataScope(张三, workflow:task)
    Acc->>Org: getManagedDepartmentIds()（如需 dept 范围）
    IAM->>Sec: 签发 Access Token（含 sub、scope 等）
    Sec-->>W: redirect + code → token
    W->>IAM: GET 用户菜单/权限（或 UserInfo 扩展）
    Note over IAM,App: 读 application_menu(workflow)<br/>按 permission codes 过滤
    IAM-->>W: 可见菜单 + 权限列表
    W->>W: 渲染侧边栏，路由守卫按 permission 校验

```
