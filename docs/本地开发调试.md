launch.json

注意 nginx mode 和 local dev mode， 2 种开发模式，1 种 hosts 配置 ip 域名映射 docker 装 nginx， 然后 deploy 执行 docker compose nginx.local
用域名访问系统，docker 里的 nginx 会解析域名， 那么可选 nginx mode 调试， 另一种是 localhost 本地模式调试。 ng mode 可以有效模拟 子域不同时 cookie 隔离情况， 而是用 local mode cookie 共享（flow和iam sso时有差别）
